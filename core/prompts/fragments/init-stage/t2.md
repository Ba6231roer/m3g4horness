## t2 (step 5)

```
5. T2 综合 — **先判聚合预算(硬闸门)**,按需 map-reduce 或 single-context:
   py .claude/mgh-core/scripts/plan_aggregate.py --node t2 --init-dir <target>/.mgh-init --budget <max-aggregate-bytes> [--materialize <target>/.mgh-init/inputs/t2]
     → stdout `{needs_reduce, repo, pending[], rollup{summary_paths[], output, done_marker}}`;`pending[]` 是 **marker-aware**(已 `.done`/`.failed` 的 shard 不在内;`checkpoints/t2/shards/` 下,重列自然收敛)
   · **needs_reduce=false**(≤ `--max-aggregate-bytes`,常见小仓)→ 既有 **single-context** `init-synthesis`(sees all T1 records, no raw code)→ 写 `controls_inventory.json` + touch `checkpoints/t2/synthesis.json.done`(行为等价于引入硬阈值前,逐字不变)。校验 + 披露见下。
   · **needs_reduce=true**(> 预算)→ **两段 map-reduce**(单 category 自身超预算 → `plan_aggregate` 自动把它确定性切成多个 ≤ 预算的 part shard(`t2-<category>-part<N>`,stdout/envelope 带 `part_index`/`part_count`;病态单条记录自动瘦身投影并留痕 `slimmed`,瘦身后仍超 → 退出码 2 不派发):
     (a) **map 段(dispatcher,一次 Bash + 重派;仅当 pending 非空)**——
       · **派发前孤儿清理(每次 fanout 派发前,MUST)**:`py .claude/mgh-core/scripts/fanout_runner.py --kill-stale --dry-run --checkpoints <target>/.mgh-init/checkpoints/t2` 审将杀 PID → `killed` 非空则去 `--dry-run` 真杀;`killed:[]` 幂等跳过。stderr 心跳行(派发事件 + 每 60s 一行在飞 `inflight=<k> unit=<id> idle=<s>s`)实时进度;非 ok 终态 stderr 附 run.log 绝对路径,失活树杀单元列于 stdout `stall_killed[]`。
       · 带 per-call `timeout` 跑一次
         py .claude/mgh-core/scripts/fanout_runner.py --tier t2 --init-dir <target>/.mgh-init --budget <max-aggregate-bytes> --checkpoints <target>/.mgh-init/checkpoints/t2 --inputs-dir <target>/.mgh-init/inputs/t2 --time-budget-ms <宿主 per-call timeout × 0.8,如 opencode 900000ms 宿主 → 720000;claude Bash 上限 600000ms → 480000> --call-timeout-s <per-call 杀上限(秒),MUST < budget×0.8,如 720000→540 / 480000→360> --stall-timeout-s <失活静默阈(秒),MUST < --call-timeout-s,如 300>
         (`--budget` MUST 与上方 gate 的 `plan_aggregate --budget` 同一值——dispatcher 内部重列 plan_aggregate 靠它保持 `needs_reduce=true`;缺省会让 plan_aggregate 落到默认预算、`needs_reduce=false` 无 `repo` 而报错)
         (fanout 内部消费 plan_aggregate --node t2 --materialize;每 shard 一个 `init-synthesis-fanout` partial:读 `pending[].input_path`,恰好写 `pending[].checkpoint_path` + touch `done_marker`;任务消息 = t2-task.md 模板逐字填充,NEVER 逐次撰写)
       · 四级超时不变式(spawn 前 fail-loud,违反退出码 2):`--time-budget-ms` MUST < 宿主 per-call `timeout` 且 MUST 显式传 `--call-timeout-s`(< budget×0.8)、`--stall-timeout-s` < `--call-timeout-s`(合规 720000/540/300 或 480000/360/300;≥20% 余量;软时限先于硬杀)→ stdout `partial:true` → **重派同一命令**(重派传 per-call `timeout` > `--time-budget-ms`)直至 `partial:false`;NEVER 手动翻页。
       · **零推进熔断(双观察点)**:每新派发 N×`--wave` 个单元或队列耗尽重列,重列磁盘终态计数;连续 N 次(默认 2)零增长且仍有待派 → 退出码 2 + `stalled:true` + `stalled_pending[]` → **停止重派**,`resume_state.py --check` 诊断;NEVER 熔断后盲目重派。
       · 退出码 2 → 看 stderr:宿主 CLI 不可用 → 走下方**手派路径**;stalled → 上行熔断 recipe。
       · 任一 shard `.failed`(终态,a stub `failed` ack / path-drift)→ **map 未全 `.done` → 不得 rollup**(rollup 只吞全量摘要,缺该 category 摘要 = 静默丢类)→ 报告缺口(boundaries[]/report.md 披露 + 向用户说明),诊断修复后 `--resume` 重入(已完成 shard 经 marker-aware 重列跳过)。
       · map 全 `.done`(stdout `partial:false`)→ 进入 (b)。
     (b) **rollup 段(单一 reduce;编排器一步)**:单一 `init-synthesis-rollup` subagent(openmode agent / claude `--agents` inline JSON 同名装载)仅吞 plan_aggregate stdout `rollup.summary_paths`(各 shard 摘要路径列表,编排器只透传路径、NEVER 整份读任何 summary 进自身上下文)→ 跨 shard——同 category 跨 part 与跨 category——canonical/competing 归并(从各摘要恢复 competing 成员)→ 写 `rollup.output`(`controls_inventory.json`)+ touch `rollup.done_marker`(`checkpoints/t2/synthesis.json.done`)。每个大模型请求 ≤ 预算。
   · **手派路径(回退,宿主 CLI 不可用)**:plan_aggregate 枚举 + 编排器逐波 spawn `init-synthesis-fanout`(逐字节透传 `pending[].input_path`/`checkpoint_path`/`done_marker`/`failed_marker`,跳过已 `.done`/`.failed`)→ map 全 `.done` 后同一 rollup(行为与 dispatcher 路径等价)。
   · 校验(两路径同):py .claude/mgh-core/scripts/validate_inventory.py --inventory <target>/.mgh-init/controls_inventory.json(`design_controls` 兼容字段 + 每条 evidence 锚点 + category→kind 归一;退出码 2 → 回退重跑;map-reduce rollup 产物 schema 不变,同样适用)。
   · 降级触发 + shard 数 + part 切分(`<category> → N parts`)与瘦身痕迹(被截字段 + 原始字节数)进 `init_manifest.json::boundaries[]` + `report.md`(无静默溢出)。
   · **宿主外手动直跑(大仓长跑逃生门)**:人可自开终端直跑 (a) 段 dispatcher 命令(无宿主超时钳制、stderr 逐波进度直读、进度 sidecar `<target>/.mgh-init/fanout_progress.t2.json` 照写);map 全 `.done` 后回会话 `/mgh-init --resume`,resume_state 仍报 t2 步(synthesis.json.done 未写)→ 重入本段:plan_aggregate pending 空 → dispatcher 幂等空转 `partial:false` → 进 (b) rollup(磁盘 marker 唯一真相源,两侧天然互斥)。
```
